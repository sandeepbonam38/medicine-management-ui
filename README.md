# 💊 Medicine Management App
This is a React + TypeScript frontend application for managing medicines.  
It connects to a .NET Web API backend.


## 🚀 Tech Stack
- React (Create React App)
- TypeScript
- Axios (API calls)
- Ant Design (UI library)
